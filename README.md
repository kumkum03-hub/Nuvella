## Overview

Nuvella is a fantasy-themed book discovery website designed to create an immersive reading experience for book lovers. The project focuses on visually appealing UI design, interactive genre exploration, responsive layouts, and engaging user interactions.

The goal of Nuvella is to make users feel as if they are stepping into a fictional world rather than browsing a traditional website.

---

## Features

* Fantasy-inspired user interface
* Responsive design for different screen sizes
* Interactive genre cards with hover effects
* Dynamic visual interactions using JavaScript
* Smooth user experience and navigation
* Custom HTML, CSS, and JavaScript implementation
